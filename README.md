# 0x11. C - printf

This ALX Software Engineering project repo contains
a custom implementation of the C standard library 'printf' function.

This project recreates the behaviour 'printf'
from scratch, handling formatted output using variadic functions.

## Features

- Supports formatted output similar to standard 'printf'
- Handles multiple format specifiers
- Uses variadic arguments ('stdarg.h')
- Modular and easy to extend

## Compilation

Compile the project using:
$ gcc -Wall -Werror -Wextra -pedantic -std=gnu89 *.c
